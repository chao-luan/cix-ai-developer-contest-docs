# CIX AI Developer Contest Docs

This repository contains documentation for the CIX AI Developer Contest.

The documentation covers:

- Hardware and software baseline
- Quick start after receiving the development board
- Local LLM/VLM runtime with llama.cpp and MNN
- CIX-P1 NPU SDK and AI ModelHub
- Multimedia SDK and FFmpeg integration
- External accelerator SDKs
- CDC cloud LLM access
- Typical AI application examples
- FAQ and troubleshooting

Documentation source files are located in the `docs/` directory.
